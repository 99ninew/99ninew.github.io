Font assets for Minimal Light

These files were downloaded from the URLs recorded in download-manifest.json.
The original Google Fonts API responses are retained as *-source.css.
fonts.css contains only the Latin font faces and uses relative local WOFF2 paths.
Place fonts.css beside the WOFF2 files, then link it before the template styles.
Remove the two Google Fonts @import declarations from the original template CSS to make the page self-contained.
